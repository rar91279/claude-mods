# claude-mods

Mods for [Claude Code](https://claude.com/claude-code): panes, bands and hooks written as plugins.

## Install

```sh
claude plugin marketplace add rar91279/claude-mods
claude plugin install <mod>@claude-mods
```

## Mods

| Mod | What it does |
| --- | --- |
| [openspec-pane](openspec-pane) | A pane listing the most recently touched OpenSpec changes with their task progress (`/openspec`) |
