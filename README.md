# claude-mods

Mods for [Claude Code](https://claude.com/claude-code): panes, bands and hooks written as plugins.

## Install

```sh
claude plugin marketplace add rar91279/claude-mods
claude plugin install <mod>@claude-mods
```

## Mods

| Mod | What it does |
| --- | --- |
| [openspec-pane](openspec-pane) | OpenSpec changes in a pane (`/openspec`): task progress and next task, a tabbed detail view (proposal, design, tasks, specs), archive with confirmation, left-open tasks to tick off, one-click setup, and a band above the prompt to open it |
