# openspec-pane

A Claude Code mod that shows the most recently touched [OpenSpec](https://github.com/Fission-AI/OpenSpec) changes in a pane, each with its task progress.

```
● add-auth
  Add auth
  ████░░░░ 1/2 · 1d
▪ old-thing
  ████████ 1/1 · archived · 3d
```

- `/openspec` opens the pane. It also opens by itself at session start when the working directory has an `openspec/changes/` folder (unasked panes are only placed in a terminal at least 144 columns wide).
- Lists active changes and those under `openspec/changes/archive/`, newest first, by the newest file directly inside each change folder.
- The second line is the first `#` heading of `proposal.md` (a `Change:` prefix is dropped); the progress counts `- [ ]` / `- [x]` lines in `tasks.md` and turns green when all are checked.
- Redraws after any Write, Edit, Bash or PowerShell call that mentions `openspec`. Edits made outside Claude show up on the next redraw.

## Options

| Option | Default | What it does |
| --- | --- | --- |
| `count` ("Changes shown") | 8 | How many changes the pane lists |

Set it in the `/config` menu, or in settings under `pluginConfigs.openspec-pane.count`.

## Install

Load it from a clone of this repository:

```sh
claude --plugin-dir /path/to/claude-mods/openspec-pane
```

or add the folder to `CLAUDE_CODE_PLUGIN_DIRS`.

## Develop

```sh
claude plugin validate openspec-pane
claude plugin test openspec-pane
```

`.claude-plugin/types/` is generated by Claude Code when the mod loads; `tsconfig.json` extends it, so `tsc -p openspec-pane` type-checks once the mod has been loaded once.
